# lucidpeak.co

Portfolio site for lucidpeak - a small product startup shipping its own apps.
Mac-desktop metaphor homepage: stacked draggable app windows, dock, terminal
signup.

## Stack

Next.js 16 (App Router) + React 19 + Tailwind v4 + TypeScript.

## Develop

```bash
npm run dev     # dev server on :3000
npm run build   # prod build
npm run lint    # eslint
```

Design rules live in `.impeccable.md`. Agent/contributor conventions in
`CLAUDE.md`. App roster (single source of truth) in `content/apps.ts`.
