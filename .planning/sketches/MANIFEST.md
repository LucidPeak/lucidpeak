# Sketch Manifest

## Design Direction

Portfolio uses macOS-window cards with construction-tape hazard strips on coming-soon projects. Locked cards need a clear "not shipped" signal without muddying the whole chrome — titlebar + hazard tape must stay **bright**, body must read **fenced off**.

## Reference Points

- Existing live Lettermatch card (emerald halo + pulsing dot)
- `.win-chrome.is-dimmed` current treatment (`app/globals.css:1132-1193`)
- Construction-tape DNA (135° stripes, yellow `#f4b94f` / black `#1a1614`)
